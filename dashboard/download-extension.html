Install in Chrome or Edge

  1. Download and extract the ZIP file.
  2. Open chrome://extensions or edge://extensions.
  3. Turn on Developer mode, select Load unpacked, and choose the extracted extension folder containing manifest.json.
  4. Open the extension options to configure the Supabase connection and device details.
